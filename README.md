# Zak 1.0 – 3D E-Commerce WooCommerce Theme

A cinematic single-brand WooCommerce theme with glassmorphism, light/dark mode, and 3D hero visuals. Copy the `zak-theme` folder into your WordPress themes directory and activate it to experience the home, shop, product, cart, checkout, account, and marketing templates.

## Elementor integration
- Elementor Theme Builder can override header/footer thanks to `elementor-location-header`/`footer` support.
- Elementor sections/widgets inherit Zak 1.0 glass variables and glow outlines via the bundled compatibility layer (`inc/elementor.php`).
- Use the Customizer to set accent gradients before building Elementor templates for consistent surfaces.

## Customizer settings
- Appearance → Customize → Zak 1.0 Identity / Experiences
- Tweak accent, gradients, blur, radius, hero texts, CTA labels, top-bar text, parallax/quick view/sticky ATC toggles, glow/noise overlays, and newsletter placeholder.

## Development notes
- Fonts: Inter + Tajawal.
- JS/CSS are lean (no heavy dependencies) and support lazy visuals, mini-cart hover, quick view, parallax, and filter drawer interactions.
